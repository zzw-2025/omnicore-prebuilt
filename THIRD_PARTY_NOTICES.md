# Third-party notices

Runtime archives are assembled from OmniCore and its upstream components. The
archive's `LICENSE` file contains the MIT terms copied from the exact OmniCore
source commit used for that build.

Windows archives also redistribute Microsoft Visual C++ runtime and OpenMP
files under the applicable Microsoft Visual Studio Redistributable terms. See
<https://visualstudio.microsoft.com/license-terms/>.

CUDA archives additionally redistribute selected NVIDIA CUDA runtime files
under the NVIDIA CUDA Toolkit End User License Agreement. See
<https://docs.nvidia.com/cuda/eula/>. NVIDIA display drivers are not included.

Not every notice applies to every archive. The generated release manifest
records the accelerator and applicable license summary for each artifact.
